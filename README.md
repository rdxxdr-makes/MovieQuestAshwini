# Movie Recommendation Quest

Website + C source for the Unit 1 C Programming project (Amrita Vishwa Vidyapeetham, B.Tech CSE-AI).

## Structure
- `index.html`, `style.css`, `script.js` : the website (open index.html in any browser)
- `c/movie_recommendation_quest.c` : the C program

## Run the C program
    gcc c/movie_recommendation_quest.c -o moviequest
    ./moviequest
