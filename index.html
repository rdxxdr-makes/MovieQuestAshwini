Problem statement

People often spend time deciding which movie to watch. This project is a simple C program that helps a user find movies by genre. It shows matching titles along with their language and rating.

Objectives

  • Build a menu-driven recommendation program in C.
  • Store title, genre, language and rating for each movie.
  • Let the user select a preferred genre.
  • Display the movies that match.
  • Practise arrays, structures, loops, conditions and functions.

How it works

The program holds a small predefined list of 10 movies. After the user enters a choice, it checks each movie one by one and prints the ones in that genre.

  1. Start the program
  2. Display genre menu
  3. Read user's choice
  4. Check movies for the genre
  5. Display matches
  6. Return to menu or exit

C program

Save as movie_recommendation_quest.c, then compile with gcc movie_recommendation_quest.c -o moviequest.

/* Movie Recommendation Quest
   A simple genre-based movie recommendation program in C. */

#include <stdio.h>
#include <string.h>

struct Movie {
    char title[50];
    char genre[20];
    char language[20];
    float rating;
};

void displayMenu(void) {
    printf("\n===== MOVIE RECOMMENDATION QUEST =====\n");
    printf("1. Action\n");
    printf("2. Comedy\n");
    printf("3. Drama\n");
    printf("4. Animation\n");
    printf("5. Science Fiction\n");
    printf("6. Exit\n");
}

void showRecommendations(struct Movie movies[], int count,
                         const char selectedGenre[]) {
    int i, found = 0;

    printf("\n--- Recommended Movies ---\n");

    for (i = 0; i < count; i++) {
        if (strcmp(movies[i].genre, selectedGenre) == 0) {
            printf("\nMovie: %s\n", movies[i].title);
            printf("Genre: %s\n", movies[i].genre);
            printf("Language: %s\n", movies[i].language);
            printf("Rating: %.1f/10\n", movies[i].rating);
            found = 1;
        }
    }

    if (found == 0) {
        printf("No movies found in this genre.\n");
    }
}

int main(void) {
    struct Movie movies[] = {
        {"Warrior's Path", "Action", "Hindi", 8.1},
        {"Sky Mission", "Action", "English", 7.8},
        {"Laugh Out Loud", "Comedy", "Hindi", 8.0},
        {"Funny Days", "Comedy", "English", 7.5},
        {"The Last Letter", "Drama", "Hindi", 8.4},
        {"Life's Journey", "Drama", "English", 8.2},
        {"Magic Planet", "Animation", "English", 8.6},
        {"Little Heroes", "Animation", "Hindi", 7.9},
        {"Future World", "Science Fiction", "English", 8.7},
        {"Beyond Earth", "Science Fiction", "Hindi", 8.0}
    };

    int count = sizeof(movies) / sizeof(movies[0]);
    int choice;
    char selectedGenre[20];

    do {
        displayMenu();
        printf("Enter your choice: ");

        if (scanf("%d", &choice) != 1) {
            printf("Invalid input. Please enter a number.\n");
            return 0;
        }

        switch (choice) {
            case 1:
                strcpy(selectedGenre, "Action");
                break;
            case 2:
                strcpy(selectedGenre, "Comedy");
                break;
            case 3:
                strcpy(selectedGenre, "Drama");
                break;
            case 4:
                strcpy(selectedGenre, "Animation");
                break;
            case 5:
                strcpy(selectedGenre, "Science Fiction");
                break;
            case 6:
                printf("Thank you for using Movie Recommendation Quest!\n");
                break;
            default:
                printf("Invalid choice. Please select 1 to 6.\n");
        }

        if (choice >= 1 && choice <= 5) {
            showRecommendations(movies, count, selectedGenre);
        }

    } while (choice != 6);

    return 0;
}

Analysis and observations

O(n)

Each recommendation request checks all n movies once, so searching takes linear time. The program reuses the existing array, so no separate database is needed.

Movies stored10
Genres5
ExitOption 6
  • Recommendations depend on the genre the user selects.
  • More than one movie can appear for the same genre.
  • Functions keep the code easy to read and maintain.
  • If no movie matches, a message is shown.
  • New movies can be added by extending the array.

Conclusion

Movie Recommendation Quest recommends movies by the user's preferred genre: Action, Comedy, Drama, Animation or Science Fiction. It shows how structures, arrays, functions, loops, conditionals and string handling work together in C. Future versions could add more movies, more filters and user-defined entries.
